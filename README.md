# Microservice-based Order Picking System
Выпускной проект по курсу **«C# Developer. Professional»**.

## Описание

Этот проект представляет собой бэкенд для сборки заказов в онлайн магазине. Реализован на базе микросервисной архитектуры с синхронным обменом по HTTP и асинхронным через RabbitMQ.
## Сервисы:
| Сервис | Назначение                                                                                                                              |
| ------- |-----------------------------------------------------------------------------------------------------------------------------------------|
| **OrdersService**| создание заказа с предварительным бронированием продуктов и отправка в сервис сборки, просмотр заказа                           |
| **OrderPickingService**| создание, завершение и просмотр сессии сборки; создание и обновление сборщиков; отправка сообщения о завершении сборки заказа в RabbitMQ |
| **StorageService**| управление информацией по продуктам; бронирование продуктов для заказа                                                                                                   |

## Стек

- C# / .NET 9
- PostgreSQL
- RabbitMQ
- Docker

## Запуск проекта
```bash
docker-compose up -d --build  
```
